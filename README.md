# Wick UI preview

Showcase of the new colour palette and the date range picker from `@npm-questionpro/wick-ui-lib`, for UX review.

```bash
npm install
npm run dev
```

To review a newer build, change the exact version of `@npm-questionpro/wick-ui-lib` in `package.json` and in `src/App.tsx`.

Vercel: import the repo; it detects Vite (build `npm run build`, output `dist`).
